# rive_muscle_heatmap (archived)

This repository is archived and no longer maintained, and the
[`rive_muscle_heatmap`](https://pub.dev/packages/rive_muscle_heatmap) package
on pub.dev is discontinued. The bundled free `.riv` has been removed from this
repo.

The heatmap lives on as two paid packs from
[Fitness Visuals](https://www.fitnessvisuals.com/?utm_source=github&utm_medium=referral&utm_campaign=flutter-package):

- **Basic, $30:** front and back views, male and female body shapes, 29
  muscles, one highlight color you toggle per muscle.
- **Advanced, $50:** everything in Basic, plus four highlight colors set at
  runtime through a 0..4 input, and tap-to-identify events that return the
  muscle name and group.

Both are one-time purchases with a lifetime single-app license and free
version updates, and both ship integration samples for Flutter, SwiftUI,
Android, and React.

- [Try the heatmap in your browser](https://www.fitnessvisuals.com/playground?utm_source=github&utm_medium=referral&utm_campaign=flutter-package)
- [See pricing](https://www.fitnessvisuals.com/pricing?utm_source=github&utm_medium=referral&utm_campaign=flutter-package)

## If you already depend on the package

Published versions stay on pub.dev, so existing apps keep resolving and
building. The terms in [LICENSE-ASSET.md](LICENSE-ASSET.md) still apply to the
asset you already have, and the code stays available under the
[MIT license](LICENSE). There will be no further releases.
